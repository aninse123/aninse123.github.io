Download the template, fill it in, then upload. One row = one company. Name is the only required field.

Import People & Ownership

Drop in an Orbis list export (.xlsx or .csv). One row = one company; the shareholders packed into each row are unpacked automatically. The file type is detected from its columns.

Include NIF (Identification numbers) so companies can be matched — BvD ID works too. People are keyed on Orbis UCI when present, so re-importing the same file never creates duplicates. Corporate shareholders become entity nodes and are linked to a CRM company when their NIF matches one.

Off by default. When on, missing companies are created with just name + NIF and tagged ownership_import so you can find or remove them later.
